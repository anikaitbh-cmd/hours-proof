# Hours Proof

A web app for Medicaid enrollment assisters that turns pay stubs and gig screenshots into proof of 80 work hours. Gemini Nano reads the documents on the laptop; the cloud only sees totals.

Full README with architecture, routing table and test results is in progress.

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # ledger math, checks, and the leak test
```
